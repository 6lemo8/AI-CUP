AI CUP 2025 — Cardiac Muscle Segmentation
Using nnU-Net v2 (2D + 3D FullRes + 3D LowRes Ensemble)
=======================================================================================================================
This repository contains the full pipeline used for our solution in the AI CUP 2025 Heart Muscle Segmentation challenge.
We adopt nnU-Net v2 as the primary AutoML segmentation framework and train three model configurations:

1.2D U-Net

2.3D Full-Resolution U-Net

3.3D Low-Resolution U-Net

Our final prediction is generated by ensembling all three configurations, which produced our best leaderboard performance.

===================== 🚀 Overview of Our Pipeline  =================================

We follow the standard nnU-Net v2 training workflow:

Set environment variables

Dataset planning & preprocessing

Training

2D (5 folds)

3D FullRes (5 folds)

3D LowRes (5 folds)

Validation --val --npz

Automatic configuration selection

Prediction on imagesTs

Final three-model ensemble

All steps are integrated into a single executable script:

run_nnunet_full_pipeline.sh

===================== 📁 Dataset Structure (nnU-Net v2 Format)  =======================

Before running the pipeline, make sure your dataset is placed in:

$nnUNet_raw/Dataset001_AICUP/
    ├── imagesTr/
    ├── labelsTr/
    ├── imagesTs/
    └── dataset.json


This is the official nnU-Net v2 dataset format.

===================== 🔧 Environment Requirements  =================================

Linux / Ubuntu environment

Python 3.10

NVIDIA GPU + CUDA

PyTorch

nnU-Net v2 installed via pip

Install nnU-Net v2:

pip install nnunetv2


Test installation:

nnUNetv2_train -h

===================== 🎯 One-Click Execution  =================================

To reproduce our full pipeline, simply run:

bash run_nnunet_full_pipeline.sh


This will automatically execute:

✔ Set environment paths
✔ Preprocessing
✔ Training (2D / 3D_fullres / 3D_lowres, 5 folds each)
✔ Validation + save predictions
✔ Model configuration selection
✔ Prediction on test images
✔ Ensemble all outputs

===================== 📌 Output Directory  =================================

Final competition-ready predictions are stored at:

$nnUNet_results/Dataset001_AICUP/ensemble_predictions/


These NIfTI files (.nii.gz) are the masks submitted to the leaderboard.

===================== ⚠️ Important Notes  =================================

Please manually adjust the three environment paths at the top of the script:

export nnUNet_raw=...
export nnUNet_preprocessed=...
export nnUNet_results=...


Because nnU-Net is installed via pip, we do not include the nnUNetv2 source code in this repository.

This submission includes only our scripting workflow, preprocessing, and ensemble logic.

===================== 🏆 Summary  =================================

Our method leverages nnU-Net v2’s AutoML capabilities to automatically determine:

network architecture

patch size

batch size

normalization

deep supervision settings

We then enhance performance by training multi-configuration models and performing cross-model ensemble, achieving strong segmentation quality on the AI CUP test set.
